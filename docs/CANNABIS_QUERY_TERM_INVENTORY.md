# Термины каннабиса из поисковых выгрузок

Источник истины для этой сводки: [query-derived-cannabis-terms.v1.json](../data/cannabis_profiles/query-derived-cannabis-terms.v1.json). Это результат разбора двух пользовательских выгрузок поисковых запросов от 21 июля 2026 года; исходные файлы оставлены вне репозитория, а их SHA-256 сохранены в JSON.

Выгрузки содержат 999 строк запросов (775 уникальных без учёта регистра). 945 строк, или 734 уникальных запроса, содержат хотя бы один термин из списка. Их суммарные показатели: 3 142 показа и 4 клика. Один запрос может содержать несколько терминов, поэтому суммы по строкам ниже нельзя складывать.

Термин не заменяет правовую проверку. Он нужен, чтобы не пропустить официальный источник из-за языка или названия продукта. Для матрицы `/wiki-truth` источником прямого cannabis-law остаётся только официальный материал, который был открыт в рендере, просмотрен глазами и признан каннабис-специфичным. `edibles` не используется самостоятельно: без явного каннабисного признака это может означать обычную пищу.
